## 研究方法與證據分級

本檔案庫刻意保留三類「不漂亮但重要」的資訊：來源之間的**數字矛盾**、廠商宣告與第三方驗證的**落差**、以及不同企業所處**階段差異**。

| 級別 | 定義 | 使用方式 |
|---|---|---|
| **A** | 原始論文／預印本、企業公告、政府規劃文件、權威媒體專訪（人民日報、新華社等） | 可直接引用，仍標註發布日期 |
| **B** | 主流產業媒體、行業聯盟報告、券商研報轉引、學會研討會紀要 | 引用時標明轉引鏈 |
| **C** | 自媒體、個人投研、未具名行業消息、廠商宣傳稿自述 | 僅作線索，明確標「待核實」 |

### 三條貫穿全庫的判讀紀律

1. **區分階段。**「已送樣」「中試貫通」「小批量供貨」「規模量產」是四個不同事實，中間通常隔著 1–2 年客戶認證期。研報常把它們混為「已突破」。
2. **區分口徑。**「等效 1.4 nm」指電晶體密度等效，不等於製程、能效、成本全面等效；「國產化率」在不同報告中可相差五倍，不宜取中值。
3. **區分來源性質。** ChinaXiv 預印本未經同行評審；廠商自測數據未經第三方實驗室獨立複測。這不使其失效，但決定了它能支撐多強的結論。

## 已知限制

- 三題皆屬 2026 年快速變動中的產業議題，數據可能於數月內被更新或修正。
- 多數量化資料來自中國大陸產業媒體與券商研報轉引，缺乏逐一回溯至企業年報或原始財報的獨立核驗。
- 報告中標註「尚無公開證據」者，意指本次查證範圍內未找到，並非斷言該事實不存在。
